# Claude-Based Chess Game Prompt Artifacts

This repository contains supplementary JSON artifacts for the Claude-based AI-generated chess game project.

Each JSON file represents one version of the iterative prompt-based development process. The files include the prompt, generated game code, metadata, version number, and multiplayer-related information.

## Folder structure

- `supplementary/claude_prompts/`
  - `v1.json` to `v17.json`: versioned Claude-generated game artifacts
  - `latest.json`: latest available generated artifact

## Purpose

These artifacts are provided to support reproducibility. A reader can inspect the prompt sequence and reuse the prompts in Claude to recreate or extend a similar browser-based chess game.
